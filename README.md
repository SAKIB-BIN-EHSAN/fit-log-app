# FitLog

## Project Name
FitLog

## Short Description
FitLog is a modern fitness workout planner and tracking app designed to help users explore exercises, build a personalized daily routine, and stay focused on their training goals. The app presents a dark, gym-inspired interface with a streamlined workflow for browsing workouts and organizing a session plan.

## Technologies Used
- Next.js
- React
- JavaScript
- Tailwind CSS
- LocalStorage for persistent workout tracking
- React Toastify for notifications

## Key Features
1. Workout Library
   - Browse a curated collection of exercises with details such as duration, calories burned, difficulty, and rating.
   - Sort workouts by duration, calories, or rating to quickly find the best fit for a session.

2. Detailed Workout Pages
   - Open each exercise to view full instructions, equipment needs, muscle groups, and performance metrics.
   - Get a complete breakdown of every workout before adding it to a plan.

3. Personalized Daily Plan
   - Add workouts to a “Today’s Plan” and keep the list organized for the day.
   - The app limits the plan to five exercises, helping users stay focused and realistic.

4. Save for Later
   - Save favorite workouts for future reference without cluttering the active plan.
   - Easily manage saved exercises and remove them when needed.

5. Progress Dashboard and Completion Tracking
   - View total exercise count, minutes, and calories for the current training plan.
   - Mark workouts as complete and track progress in a clean, motivating dashboard.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open your browser and visit:
   ```bash
   http://localhost:3000
   ```

## Project Goal
FitLog aims to make workout planning simple, efficient, and motivating by combining a polished UI with practical daily fitness organization tools.
